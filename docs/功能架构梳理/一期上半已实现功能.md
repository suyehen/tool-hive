# ToolHive 一期上半已实现功能

> 文档版本：v1.1  
> 更新日期：2026-08-24  
> 文档目的：按功能架构汇总一期上半部分已经完成开发的管理侧功能。  
> 范围说明：本文只保留总体架构和功能概述，不展开接口字段、测试结论和问题整改；一期下半待实现范围见 [一期下半待实现功能](./一期下半待实现功能.md)。

## 1. 总体功能架构

一期上半实现的是 ToolHive 的管理侧基础能力。管理前端通过管理 API 访问账号、权限和调用系统配置，数据分别落在 PostgreSQL 和 Redis 中。

```text
管理前端
   ↓
管理入口 / 管理 API
   ↓
管理安全与权限
   ↓
账号、角色、调用系统配置
   ↓
PostgreSQL + Redis
```

ToolHive 仍是一个统一应用。管理模块与一期下半的工具运行模块共享应用、部署和生命周期，仅使用不同的路由、身份凭据和控制链路。

## 2. 应用基础架构

### 已实现功能

- FastAPI 应用入口、生命周期管理和健康检查。
- 配置加载，支持默认配置、`.env`、YAML 和环境变量。
- PostgreSQL 异步数据库访问和 Redis 客户端。
- 统一异常基础、时间处理、网络校验和 ID 生成。
- Outbox 后台投递基础设施。
- 管理入口标识、可信代理和来源 IP 基础校验。
- 数据库初始化、配置校验、安装、启动和基础验收脚本。

## 3. 管理安全架构

### 已实现功能

- 账号、密码和图形验证码登录。
- 图形验证码生成、刷新、短期保存和一次性消费。
- 密码哈希、密码强度校验、密码历史和临时密码。
- 首次登录强制修改密码及临时密码过期控制。
- 登录失败限制、账号锁定和管理员解锁。
- 互斥登录、会话超时、会话撤销和强制下线。
- CSRF Token、登出、会话查询和密码修改。
- 管理 API 会话校验与写请求 CSRF 校验。

> 一期管理登录不包含 MFA、TOTP 和恢复码。

## 4. 管理权限架构

```text
管理账号
    ↓
账号与角色关联
    ↓
后台角色
    ↓
角色与操作项关联
    ↓
管理操作项
```

### 已实现功能

- 管理账号创建、资料维护、启用、禁用、离职和密码重置。
- 首个超级管理员初始化。
- 超级管理员角色和最后一个超级管理员保护。
- 后台角色创建、修改、启停和账号关联。
- 管理操作项定义、同步、查询和分配。
- 管理 API 操作级鉴权和默认拒绝。
- 超级管理员实时拥有全部有效管理操作项。
- 管理前端根据操作项控制菜单和按钮展示。

## 5. 调用系统管理架构

```text
调用系统
    ├── 基本资料与环境
    ├── 生命周期
    ├── 公钥
    ├── 来源 IP 规则
    ├── 运行策略
    └── 工具 / 能力包范围
```

### 已实现功能

- 按外部项目和运行环境登记调用系统，并生成稳定 `system_id`。
- 调用系统草稿、启用、停用、恢复和注销。
- 负责人、联系方式、标签、有效期和停用原因维护。
- 公钥新增、查询、启用、停用和撤销。
- IPv4、IPv6、CIDR 和 `*` 来源 IP 规则管理。
- 运行 API 范围、QPS、并发、日配额、超时和熔断策略配置。
- 工具和能力包范围配置。
- 系统级紧急禁用和解除。
- 启用或恢复前的基础配置完整性检查。

## 6. 管理支撑架构

### 已实现功能

- 管理变更审计模型和审计服务。
- 账号、角色、调用系统及安全配置变更审计。
- 审计摘要脱敏、操作人和操作时间记录。
- 成功变更与审计同事务提交，关键失败事件独立记录。
- Outbox 投递任务查询和失败重试管理。
- 管理员初始化和部署基础说明。

## 7. 管理前端架构

### 已实现页面

- 登录页：账号密码和图形验证码登录。
- 首页：账号状态和权限信息概览。
- 修改密码页：密码修改和会话刷新。
- 管理账号页：账号列表、创建、状态管理、重置密码、离职和角色分配。
- 后台角色页：角色维护、操作项分配和账号关联查看。
- 调用系统页：调用系统、公钥、IP 规则、运行策略和工具范围维护。

## 8. 上半完成边界

一期上半已完成管理侧配置和安全基础，暂不包含以下一期下半能力：

- Catalog、Provider、工具、工具版本和执行绑定；
- `/api/runtime/v1/**` 运行 API；
- 调用系统请求签名和 Nonce 防重放；
- ToolContext 和工具调用控制；
- 工具 Resolve、Discover、Execute 和高风险确认；
- HTTP Provider、受控出站和 SSRF 防护；
- Chroma 检索、关键词降级和运行 Trace 闭环。
