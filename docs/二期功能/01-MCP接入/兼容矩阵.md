# ToolHive 二期 · MCP 接入客户端兼容矩阵

> 文档版本：v0.1
> 更新日期：2026-09-07
> 目的：记录各 MCP 客户端的接入方式、协议版本协商、认证兼容性、需确认工具处理与受限项，作为实连验收依据。

## 1. 接入信息

- MCP Server：ToolHive（Streamable HTTP）
- 端点：`http://<host>/mcp/`（部署环境替换 host）
- 认证：`Authorization: Bearer <Token>`（一客户端一 Token，明文仅签发时展示一次）
- 需确认（高风险/写操作）工具：当前一律拒绝、不执行（D1 延后），限制项将持续登记到《待后续实现功能》

## 3. 实测方法与回填

- Inspector：`npx @modelcontextprotocol/inspector` 连接 `http://127.0.0.1:<port>/mcp/` 并配置 Bearer Token；记录握手与工具调用结果后回填本表。
- Cursor / Claude Desktop：按对应产品远程 MCP 配置界面接入，填写认证方式与实测结论。
- 回填后同步更新《待后续实现功能》受限项与《开发计划》阶段 6 补充记录。

## 4. 已知限制

- 需确认工具当前不执行（D1 延后），实连时表现为"拒绝并提示"。
- SDK 发布 OAuth 资源元数据的副作用已在阶段 2 随 SDK 原生鉴权移除，不影响静态 Bearer。
